# Crypto Data Explorer

An independent, beginner-friendly educational web application for exploring historical cryptocurrency price trends in plain English.

## Features
- **Interactive Price & Activity Charts:** View daily end-of-day prices, 24-hour trading activity, optional 7-Day and 30-Day Averages, and a **Drops from Peak** view.
- **Plain-English Explanations:** Includes beginner-friendly labels, "What does this mean?" helper tooltips, and a glossary for reading market cap and trading volume.
- **Multi-Currency & Flexible Timeframes:** Explore 20 major cryptocurrencies across GBP, USD, EUR, CAD, AUD, and JPY over `7D`, `30D`, `90D`, `YTD`, `1Y`, or custom dates within the past 365 days.
- **AI Period Recap:** Optional plain-English summary of verified historical figures for the selected date range.
- **Daily Historical Records Table:** Sortable, paginated end-of-day data table with Light and Dark mode support.

## Data Source
Historical market data powered by [CoinGecko](https://coingecko.com).
